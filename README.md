# ProjectS4
The **Warehouse Stock Manager** is a Python-based command-line application designed to help users manage inventory efficiently. It allows users to:

* **View current stock** with low stock alerts
* **Add new items** to the inventory
* **Update quantities** by stocking in or out
* **Export stock data** to a CSV file
* **Save and load** inventory data using a JSON file for persistence

This tool is ideal for small businesses or personal projects needing basic stock control without a database or complex interface.
